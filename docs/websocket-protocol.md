# WebSocket protocol

Endpoint: `/ws` (`wss://` in production). Every frame is a JSON text frame `{"type": "...", ...}`.

## Handshake
1. Open the socket. 2. Within 5 s send `{"type":"auth","token":"<bearer token>"}`.
3. The server replies `ready`. Until then nothing else is accepted.

| Close code | Meaning | Client should |
|---|---|---|
| 4401 | Bad/expired token, or first frame wasn't `auth` | Go to login. Do not retry. |
| 4408 | No `auth` in 5 s, or no frames for 70 s | Reconnect (with backoff). |
| other | Network drop, server restart | Reconnect (with backoff). |

After **every** (re)connect: wait for `ready`, then re-fetch the chat list over REST. Anything that
happened while disconnected is picked up there; it is not replayed over the socket.
Send `{"type":"ping"}` every 25 s; the server answers `pong`.

## Client -> server
| type | payload | notes |
|---|---|---|
| `auth` | `token` | first frame only |
| `message.send` | `conversation_id`, `client_id`, `body` | `client_id` is generated by the client; resend the same one after a failure |
| `message.read` | `conversation_id`, `up_to_message_id` | marks your unread messages up to that id as read |
| `typing` | `conversation_id`, `typing: bool` | send `true` on first keystroke, again every 10 s, `false` after 3 s idle or on send |
| `ping` | – | heartbeat |

## Server -> client
| type | payload | sent to |
|---|---|---|
| `ready` | `user_id`, `online_user_ids` | the new socket |
| `message.ack` | `client_id`, `message` | the sending tab. One tick. `message.status` is the current state. |
| `message.new` | `message` | recipients' tabs, and the sender's *other* tabs (a REST send also reaches the sender's own tabs: dedupe by `message.id`) |
| `receipt.update` | `conversation_id`, `message_ids`, `user_id`, `status` (`delivered`/`read`), `at` | the messages' sender. `user_id` is the recipient who moved. Bubble status = highest across recipients. |
| `read.sync` | `conversation_id`, `up_to_message_id` | the reader's other tabs |
| `typing` | `conversation_id`, `user_id`, `typing` | other active members. Hide the dots after 15 s without a refresh. |
| `presence` | `user_id`, `online`, `last_seen_at` | people with a 1:1 chat with that user |
| `conversation.updated` | `conversation_id` | members (and a just-removed member): re-fetch that chat over REST |
| `error` | `code`, `detail`, `client_id?` | the socket that caused it; `client_id` says which send failed |
| `pong` | – | reply to `ping` |

`error.code`: `invalid_event`, `bad_request`, `forbidden`, `not_found`, `conflict`, `internal`.
The socket stays open after an `error`.

## Message status on the sender's bubble
`sending` (client only) -> `message.ack` -> **sent** -> `receipt.update delivered` -> **delivered**
-> `receipt.update read` -> **read**. "Failed" is client-only: no ack after a timeout, then retry
with the same `client_id`.
